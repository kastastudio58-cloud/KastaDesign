# Сайт Kasta Design

Одностраничный сайт бренд-дизайнера (RU + EN) по макету Figma «Бренд Kasta», страница «Сайт».
Сделан на [Astro](https://astro.build), контент редактируется через админку [Keystatic](https://keystatic.com).

## Как запустить у себя

Нужен Node.js 22 или новее.

```bash
npm install      # один раз
npm run dev      # сайт: http://localhost:4321, админка: http://localhost:4321/keystatic
npm run build    # проверочная сборка
```

## Что где лежит

| Что | Где |
|---|---|
| Тексты, цены, проекты, статьи, отзывы, ссылки | `src/content/` (меняются через админку) |
| Загруженные фото | `public/images/` (кладутся туда админкой) |
| Блоки главной | `src/components/sections/` |
| Страница проекта, статьи, политики | `src/components/*Page.astro` |
| Цвета, шрифты, отступы (токены из Figma) | `src/styles/global.css` |
| Стили блоков и адаптив | `src/styles/blocks.css`, `src/styles/pages.css` |
| Подписи интерфейса (кнопки, меню) на двух языках | `src/i18n/ui.ts` |
| Схема админки (какие поля можно редактировать) | `keystatic.config.ts` |

## Админка

Откройте `/keystatic`. Разделы:

- **Тексты и фото главной** — все заголовки и тексты блоков, фото первого экрана, «Обо мне», картинки процесса, иллюстрация комьюнити.
- **Услуги и цены** — строки таблицы «С чем ещё могу помочь».
- **Отзывы** — текст, время, колонка на компьютере.
- **Проекты** — кейсы «На каком этапе» и сетка «Ещё больше работ». У каждого проекта своя страница и галерея на любое количество фото.
- **Статьи** — пока статья пустая, на её странице показывается «Статья скоро появится».
- **Ссылки, логотип и счётчик** — контакты, подпись для футера, картинка превью, номер Яндекс Метрики.

У каждого текста два поля: RU и EN. Если английское поле пустое, показывается русский текст.
Пока фото не загружено, на его месте видна аккуратная заглушка «Фото скоро появится».

## Публикация (GitHub + Vercel)

1. Создайте репозиторий на GitHub и загрузите в него проект.
2. На [vercel.com](https://vercel.com) войдите через GitHub → **Add New → Project** → выберите репозиторий → **Deploy**.
3. В настройках проекта Vercel → **Environment Variables** добавьте:
   - `PUBLIC_GITHUB_REPO` = `ваш-логин/имя-репозитория` — админка начнёт сохранять правки прямо в GitHub;
   - `SITE_URL` = адрес сайта (например, `https://kasta.design`), когда появится домен.
4. Откройте `https://ваш-сайт/keystatic` — Keystatic предложит создать GitHub App и сам выдаст
   переменные `KEYSTATIC_GITHUB_CLIENT_ID`, `KEYSTATIC_GITHUB_CLIENT_SECRET`, `KEYSTATIC_SECRET`.
   Добавьте их в Vercel и пересоберите проект.

После этого любое сохранение в админке создаёт коммит в GitHub, и Vercel автоматически пересобирает сайт (1–2 минуты).

## Яндекс Метрика

1. Зайдите на [metrika.yandex.ru](https://metrika.yandex.ru) → **Добавить счётчик** → укажите адрес сайта.
2. Скопируйте номер счётчика (только цифры) в админке: **Ссылки, логотип и счётчик → Номер счётчика**.

Метрика подключается только после того, как посетитель нажмёт «Хорошо» в плашке о cookies.
Пока номер пустой, ни плашки, ни Метрики на сайте нет.
